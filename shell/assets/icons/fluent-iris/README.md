# Ícones Fluent do pacote "Fluent" do iRiS

Usados pelo `IrisSquircle` quando `iris.appearance.icons.style = "fluent"` (ícones soltos, sem placa).
Cada arquivo tem o nome do glifo Material Symbols que o iRiS já usa (`settings.svg`, `palette.svg`…), então
o código procura `<glifo>.svg`; glifo sem arquivo cai no Material Symbol solto.

`MAPA.txt` lista de qual ícone Fluent cada um saiu (tamanho 24 regular; 20 quando não há 24).

Origem: Microsoft Fluent UI System Icons, pacote npm `@fluentui/svg-icons`
(https://github.com/microsoft/fluentui-system-icons).
